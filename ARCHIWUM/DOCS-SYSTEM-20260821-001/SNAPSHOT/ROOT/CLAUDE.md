# CLAUDE.md — start pracy nad Skanerem wykresów

Obowiązują wszystkie reguły z `AGENTS.md`. Przed odpowiedzią lub zmianą przeczytaj kompletnie:

1. `DOKUMENTACJA/MASTER-PROJEKT.md`;
2. `DOKUMENTACJA/STAN-AKTUALNY.md`;
3. `DOKUMENTACJA/00-STEROWANIE/ZASADY-PROJEKTU.md`;
4. `DOKUMENTACJA/04-DECYZJE/DECYZJE-PROJEKTOWE.md`;
5. wskazany AS-BUILT i aktywną paczkę.

Nie zakładaj, że pamięć poprzedniego czatu jest dostępna. Pliki projektu są pamięcią trwałą. Brakujące informacje oznacz `UNVERIFIED/TO RECOVER`, a konflikt — `STOP/DECISION REQUIRED`.

Nie uruchamiaj produkcji ani nie zmieniaj kodu bez kompletnego kontraktu aktywnej paczki.
